# Волонтерский проект: EDA и ML-классификация жертвователей для фонда Бюро добрых дел
Data Science & Machine Learning проект по анализу поведения жертвователей благотворительного фонда с целью оптимизации сбора средств и прогнозирования оттока.

## Задача
Из пула клиентов, совершавших пожертвования за последний год, выявить тех, кто потенциально готов увеличить частоту или размер взносов. Дополнительно — выделить маркеры поведения пользователей, которые склонны прекратить пожертвования.

## Данные
* Реальные исторические данные фонда по ~4 000 жертвователей за несколько лет (транзакции, динамика платежей, email-активность).

## Стек технологий
* Язык: Python
* ML-модели: CatBoost, Random Forest
* Метрики: RFM-анализ (Recency, Frequency, Monetary)
* Библиотеки: Pandas, NumPy, Matplotlib, Seaborn
* Инструменты: Jupyter Notebook

## Что реализовано в проекте:
1. Предобработка и очистка данных: Обработаны пропуски, удалены дубликаты. Категоризированы города (Москва, СПб, другие регионы РФ, заграница) и назначения платежей (пожертвование, именное пожертвование, SMS).
2. Feature Engineering (Генерация признаков): Сформирован агрегированный датасет по жертвователям (1206 строк). Добавлены признаки: lifetime, время с первого/последнего платежа и email-активности, общая сумма, медиана и средний чек, а также средний период между пожертвованиями.
3. Сегментация доноров: Жертвователи разделены на 4 класса по методологии RFM.
4. Обучение моделей: Подготовлены и обучены базовые модели классификации без подбора параметров.
   * CatBoost Classifier: Accuracy = 0.90
   * Random Forest: Accuracy = 0.87

## Планы по доработке:
* Расширить Feature Engineering: добавить признаки изменения средней суммы пожертвования (первая vs вторая половина lifetime).
* Настроить гиперпараметры моделей (GridSearchCV / Optuna) для улучшения качества.
* Выделить новых пользователей (до полугода активности) в отдельный датасет и спрогнозировать их будущий RFM-класс.
